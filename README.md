🎵 SWAR Music

«SWAR Music — Your music, your vibe.»

SWAR Music is a modern, smooth, and feature-rich Android music player built with Kotlin, designed to provide a clean and enjoyable music experience while keeping your music library easily accessible.

The official website is available for project information, features, screenshots, and APK releases.

🌐 Official Website: https://swarmusicplayer.netlify.app/
📦 GitHub Repository: https://github.com/sumitkumartiwari19-sudo/SWAR-Music

---

✨ Features

🎵 Music Playback

- High-quality local music playback
- Play, pause, next, and previous controls
- Seek through songs
- Background playback
- Media controls
- Queue management
- Automatic next-track playback

📚 Music Library

- Browse your complete music collection
- Recently played songs
- Liked songs
- Downloaded songs
- Albums
- Artists
- Playlists
- Organized and easy-to-navigate library

❤️ Liked Songs

- Like your favorite tracks
- Dedicated Liked Songs section
- Quickly access your favorite music

📋 Playlists

- Create and manage playlists
- Add songs to playlists
- Remove songs from playlists
- Play an entire playlist
- Custom user playlists

🎧 Modern Music Player

- Mini player
- Expanded full-screen player
- Smooth player transitions
- Album artwork
- Song information
- Progress/seek bar
- Playback controls
- Queue access

🎨 Modern UI

- Clean and modern interface
- Smooth animations
- Responsive layouts
- Dark mode support
- Light mode support
- System theme support
- Glass-style visual elements
- Designed for a smooth music experience

📝 Lyrics

- Lyrics support
- Embedded/synchronized lyrics support where available
- Dedicated lyrics experience

📂 Local Music

- Scan and access music stored on your device
- Support for common audio formats
- Local-first music experience
- Manage your music without depending on an online streaming service

🔔 Background & Media Controls

- Background playback
- Media notification
- Lock-screen/media controls
- Control playback without opening the app

⚡ Performance

- Optimized Android experience
- Smooth scrolling and animations
- Efficient music-library handling
- Lightweight and responsive UI

🚀 Getting Started

Requirements

- Android Studio
- Android SDK
- Kotlin support
- Android device or emulator

Clone the Repository

git clone https://github.com/sumitkumartiwari19-sudo/SWAR-Music.git

Open the Project

1. Open Android Studio
2. Select Open
3. Select the cloned "SWAR-Music" directory
4. Allow Gradle to sync
5. Connect an Android device or start an emulator
6. Build and run the application
